# NOTE on /radio (unlisted since 2026-08-29):
# /radio is deliberately NOT disallowed for the major search engines. It serves
# `noindex, nofollow` in both its page metadata and an X-Robots-Tag header, and
# it has been pulled from sitemap.xml. A crawler must be allowed to fetch the
# page in order to see that noindex and drop it from the index — blocking it
# here instead would leave the already-indexed URL sitting in results with no
# way for Google to learn it should go. Once Search Console shows /radio gone
# from the index, uncomment the two Disallow lines marked BLOCK-LATER below to
# stop the crawling as well.
